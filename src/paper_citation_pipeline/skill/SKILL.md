# 本地论文转换、证据核验与交付

使用固定的 `paper-citations` 工具，不临时重写解析或填表。0.9为开发版；自动检查通过不等于已经实测达到95%召回率。日常研究助理使用图形工作台，不要求输入终端命令。

## 输入

首页：01论文目录，02模板目录并选择组织/变体，03 API Key。按 `模板/<组织>/` 加载 `引用采集模板.xlsx`、`名称变体.json`、`字段映射.json`及可选`报告目录.json`；缺文件或组织ID不符则停止，不默默替换模板/变体。Key只驻留进程，不写配置、代码、日志或交付包。

必须使用已有本地 `id_state` 编号文件；首次建档需明确最后已用论文号和记录号。不能根据文件名猜编号，也不能为重跑回退编号。只有英语正文纳入；非英语排除，语种不确定保留待确认。

Agent执行已有项目：`paper-citations run --config /项目/run.json`。新项目使用 `setup --non-interactive` 并提供已取得的输入、目标、模板、变体和编号文件；不进入等待键盘输入的向导。CLI不在PATH时使用本skill的runtime.json解释器。GROBID仍为独立本地服务，Docling用`[full]`依赖。

## 本地处理

- GROBID仅接收原始PDF，localhost绕过代理；Docling并行提取结构。保存原始TEI和解析缓存。JSON为主数据，MD仅阅读，不从MD反推引用。
- 0.9模型在GROBID/Docling转换完成后审查所有已提取书目条目，不仅规则筛出的候选。dev3从原PDF参考文献标题页独立选择至文末进行区域补查，保留相邻批次重叠行及逐行覆盖记录；未定位标题或有未核验行不算完整覆盖。缺项、混合或损坏条目未解决则阻止交付；当前不自动补造缺失书目。
- 作者/共同作者、出版方、委托方、仅提及分开记录。共同作者纳入，不把组合署名变成全局机构别名。模型署名、标题和年份必须是输入原文子串；可以证据约束地裁去混入的图注，不能生成参考文献原文。
- 确认署名后在原始文字层反向查找作者年份和方括号数字范围。数字号来自原文印刷编号，不根据书目顺序猜。上标/脚注沿用既有定位与恢复规则，未解决情况留待核验。
- 引用上下文模型选择原PDF行ID及字符范围，程序回取原文；不能让模型改写或编造段落。当前为有界邻域，超出窗口或预算需保留待解决状态，未实现无限工具调用或自动多模态兜底。
- 检查机构名称出现的处理状态及论文标题，避免把图注、页眉和期刊名当文献字段。引用收录与报告名称匹配分开：具体报告未匹配，Excel填0，不删除引用。
- 表格结构、标题、注释和正文文字保留。压缩交付不是图像保真存档，不能声称图像内所有文字、隐含转引和全篇内容均被保留。
- 本地字段和Excel逐格映射由代码核验。旧版每10篇三次结构摘要API不再自动调用，模型预算用于证据语义检查。

模型请求缓存绑定输入/提示词/模型配置；失败或中断不自动重试。同任务相同输入复用结果；需重试失败请求时另建任务。每篇最多40次请求，累计输入最多240000字符，输出上限配额65536 tokens；单次最多24000输入字符，各阶段限制1024–4096输出tokens。达到任一上限留为待核验，不默认为通过。没有API时可以完成本地转换，但不能生成已通过的交付包。真实请求/usage见`semantic-review/`；模拟测试不能称作真实智谱调用。

## 交付与删除原件

每篇JSON保存`local_verification`及证据；全批`upload-readiness.json`是当前交付状态。完成本地Excel不等于可上传。

只有所有纳入论文的核验通过、未解决项清零、JSON未在核验后改动、Excel回读和来源哈希一致时，生成`upload-*.zip`。包内为`json/*.json.gz`、总表和清单，不含PDF；工具不上传也不自动删除PDF。失败、中断或重跑会使当前交付指针失效。

压缩JSON自带文字池、页面行/坐标、书目、引用关系、上下文、Docling结构、编号及核验信息。通过`decode-cloud`可在没有PDF/TEI的环境还原；图片二进制不保留。原始PDF SHA256用于跨研究助理批次识别同一文献，不以本地文件路径作为身份。

不能因自动检查通过就宣称达到95%准确率或建议全面删除原PDF。开发版需要真实模型盲测和预先确定的抽样验收；待解决论文必须保留本地PDF。用户自行决定已验收资料的原件处置，工具无自动删除功能。

工作台“交付包状态”查看结果。CLI可显式执行：

```bash
paper-citations prepare-upload --output /项目/output --workbook /项目/output/citations.xlsx
paper-citations decode-cloud /下载/论文.json.gz --output /下载/论文.decoded.json
```

先读[本地配置](references/config.md)了解run配置；[0.8历史记录](references/legacy-0.8.md)仅用于旧版本故障定位，不覆盖本流程。开发代码不等于授权上传论文、上传云端数据或发布GitHub。
