# 0.9.0.dev4 · 并发解析与引用核查开发版

## 新增与修复

- 中央台账、任务租约和心跳、资源保护、服务恢复以及最近一小时落账与token趋势。
- 解析和GLM审查两路并发；解析子进程退出释放内存，审查期间解析下一篇；使用持久缓存并保持单路编号和导出。
- 修复解析准备阶段与审查阶段争用编号锁的问题；GROBID没有有效输出时阻止继续进入Docling。
- 支持GLM-5.3-Flash的thinking/reasoning请求设置，保留已有模型的配置行为。
- 完整参考文献审查、组织变体扫描和漏检校对；已有报告目录匹配、正文反查、叙述式引用恢复及来源归属判定。
- 联合署名或证据不足可保留待裁决，不要求预先完成所有作者核定。
- 更新UNEP空白采集模板的编号、版本及统计口径说明，同步名称变体；发布字段映射与报告目录。
- 提供完整、简化和引用判定三种Mermaid框图，GitHub可直接显示，并附可编辑源文件。

## 下载与兼容性

提供Python wheel、源码包、Mac/Windows安装脚本包、独立模板包及SHA256校验清单。安装包需要Python 3.11以上（建议3.12）、联网安装依赖，以及独立GROBID服务。它们不是内嵌所有运行时的独立可执行文件。Windows完整PDF解析尚未实机验证。

本版仍是开发预发布。候选、待裁决和已确认引用分别统计；未检出不代表确定没有引用。运行速度取决于论文、解析资源、模型延迟和命中情况，不在发布说明中承诺固定吞吐提升。

## 升级

参见[安装说明](../platform-releases.md)和[台账部署](../central-ledger.md)。沿用项目编号档案，升级台账前处理程序版本与配置指纹绑定；不要直接重置旧队列或编号。

## 验证范围

发布前在macOS隔离环境运行337项测试，全部通过。测试覆盖两路流水线、编号锁、资源保护、台账、GLM传输、来源恢复、模板字段映射与空白采集区。本次发布测试不调用付费模型API，不重新处理正式论文。生产数据回跑结论不能代替对每个引用的核验。
