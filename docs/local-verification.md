# 0.9 本地核验与无PDF云端交付

此版本是开发版，提供受约束的模型证据审查、失败关闭的交付门槛和自包含JSON格式；尚未证明95%准确率。既有0.8原始解析结果不会被覆盖，研究助理日常仍从图形工作台开始。

## 流程

1. 英语筛选，原PDF本地GROBID/Docling转换，原始输出保留。
2. 模型批量检查所有已提取书目；角色、标题、出版年份和修剪的条目必须有逐字证据。保留原值。
3. 对确认作者/共同作者的条目进行原始文字层反向检索；作者年份没有逗号也可识别；[15–17]支持原文印刷编号16，重复出现分别建边。既有上标、脚注模块继续使用。
4. 原始参考文献页面与清单对账，发现遗漏/混合条目阻止交付。暂不自动补建缺失书目。
5. 模型检查引用附近的原PDF文字行，选择行ID和字符范围重建段落；跨块显式分段。不会生成或改写原文。窗口不足保留待解决，当前无自动图片/OCR兜底。
6. 核查目标名称出现的处理状态和论文标题；本地未解决异常不能被模型的“通过”覆盖。
7. 逐篇保存本地Excel，结束时做总表回读与哈希绑定；全部满足后才生成upload ZIP。

## API预算与失败

`api_config`格式沿用endpoint/model/timeout/max_tokens/json_mode。Key只通过工作台或PAPER_CITATIONS_API_KEY环境变量提供。使用现有兼容Chat接口，智谱未设置特殊绕过路径。

每篇最多40请求/240000输入字符/65536预留输出tokens；单次输入24000字符，各阶段输出1024–4096 tokens，不自动重试。真实用量以服务返回usage为准，字符限额不是token估价。无Key、响应缺项、凭空引用、截断、接口失败、超预算均保持待核验。缓存精确绑定输入和模型配置；失败重试需显式新任务，不能复用失败文件伪称调用成功。

## 云端格式

`paper-citation-cloud/1`包含payload与text_pool，长的重复文本只存一次，再用gzip压缩。payload包含页面文字/行/坐标、正文与章节、书目、出现位置/引用边、候选记录与原文范围、Docling表格及说明结构、编号与模型证据。没有图片二进制、原PDF和大部分重复原始解析中间态。

`decode-cloud`进行解引用并校验decoded_sha256，无需本地PDF或TEI。来源以PDF SHA256标识，保留原文件名，去除本机绝对源路径。总表的既有本地证据链接是本地工作链接；云端检索应按manifest中的source_sha256、paper_id和JSON内numbering/record_id关联，而不是依赖这些本地路径。

每次正常运行开始即撤销当前交付指针，历史ZIP保留；只认当前upload-readiness.json的ready状态和package_sha256。再次修改JSON或Excel后须重新核验，不能沿用旧通过状态。没有全部通过的论文批次不生成部分正式上传包，避免误把部分结果当完整批次。

## 开发版限制

- 自动检查是一组必要条件，不是95%召回率的统计证明；混合文献、解析遗漏、图像内引文、隐含转引和长段落仍可能阻塞。
- 实测API的分类质量、误报率、费用、延时仍需盲测；测试中模拟返回只验证代码，不代表智谱效果。
- 交付是文字引用证据存档，不是整篇PDF视觉内容替代物。未通过论文保留PDF，软件不自动删除任何原件。
- 未实现云端上传、跨研究助理主库自动合并或百万行Excel分片；当前输出稳定内容标识与来源清单供下一阶段对接。不能直接覆盖已有云端总表。
- Mac/Windows共用Python源码；未做Windows实机打包或安装器验证。

## 0.9.0.dev2：三篇真实模型试跑

2026-09-28，以一篇既有漏检和两篇未处理英语论文做真实 glm-4.7 试跑，独立原文对照发现四处目标引用。修正后引用定位为4/4，报告标题和出版年份对应正确；完整段落为3/4，不能据此宣称达到95%总体准确率。三篇均有未解决核验项，没有生成可交付包。

本次增加目标机构署名约束，避免把“条目有作者”误解成“目标机构是作者”；反向匹配优先保留原文完整共同署名，避免模型漏列合作者导致漏检。原始引用先定位再与独立恢复结果去重。上下文校验拒绝截断单词、句末未完成或删掉已有候选内容的模型输出；失败保留原提取文本和异常，不假定完整。模型误判跨栏、跨页或段落边界仍是限制，当前没有自动纠错闭环。

输出预算按已返回的 completion_tokens 结算，未知用量保留预留额度；失败请求也记录返回用量与原始决策，失败不自动重试。Excel兼容缺少 raw_author_label 的旧共同作者记录。232项代码测试通过；这不是232篇论文准确性评估。

## 0.9.0.dev3：独立参考文献区域覆盖

参考文献标题从原PDF文字行独立识别，兼容反引号、项目符号、章节号等。审查范围从标题页覆盖到文末（含末尾说明文字，模型区分正文/书目），不再仅依赖解析器返回书目的页面。每批核心行唯一分配，前后各保留12行边界上下文。`coverage`记录expected_line_ids、checked_line_ids与unchecked_line_ids；只在独立找到标题且全部核心行检查完成后认可区域覆盖。找不到标题时尾部回退仍可供检查，但不能宣称完整覆盖。

仍未实现模型与GROBID/Docling独立并行、缺失书目自动重建或异常自动修复。本修复避免把未送审页面默认为检查通过；模型自身仍可能漏判。

真实glm-4.7区域复测：P002440第17–20页136行、P046149第5–6页134行全部核心行完成检查；236项代码回归测试通过。本次只重查区域，未重置原论文的整篇blocked状态，区域通过不等于全文引用准确率保证。送审坐标精简到小数点后一位以减少请求体，原始PDF/JSON证据精度保持不变。
